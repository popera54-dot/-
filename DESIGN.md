# 🎬 Visual & UX Direction — Teen / Young Adult

The target feeling is a premium cinematic escape room for teenagers and families.

## Core feeling

Think:

- cyber-thriller
- secret military terminal
- hacked operating system
- ancient Greek symbolism reimagined as technology
- cinematic game UI
- high-stakes but fun

Avoid:

- kindergarten / preschool graphics
- cartoon mascots
- oversized childish emoji buttons
- generic web-dashboard styling
- cheap clip-art
- excessive rainbow colors
- playful bubble typography

## Art direction

The visual system combines:

1. **Dark cinematic base**
   - deep black / graphite backgrounds
   - subtle depth and atmospheric gradients
   - controlled use of fog, particles and vignettes

2. **Cyber security layer**
   - terminal fragments
   - scanning reticles
   - holographic panels
   - signal noise
   - data rain
   - system diagnostics
   - restrained glitch effects

3. **Greek layer**
   - Greek key / meander geometry
   - bronze / gold accents
   - ancient symbols rebuilt as modern interface components
   - silhouettes, helmets and armor references used sparingly

4. **Hanukkah layer**
   - menorah / oil / dreidel motifs
   - warm flame-inspired highlights against the dark interface
   - symbols integrated into the technology rather than pasted on top

## Typography

Primary UI:
- clean modern sans-serif
- strong hierarchy
- compact labels
- generous spacing

System / hacker text:
- monospaced type
- uppercase technical labels
- small diagnostic readouts

Hebrew and English must feel like one coherent premium UI.

## Motion

Motion is part of gameplay, not decoration.

Use:

- stage entrance transitions
- camera-like zooms
- controlled screen shake
- scan sweeps
- flickering status lights
- glitch bursts
- timer pulses
- success shockwaves
- failure distortions
- particle reactions
- progressive environmental changes

Animations must remain readable and purposeful.

## Teen-level puzzle UX

Puzzles should feel:

- clever rather than childish
- tense rather than silly
- cooperative rather than educational
- visually discoverable
- satisfying to solve

A teen should look at the screen and feel:
**"This looks like a real game."**

not:
**"This is a children's activity."**

## Per-stage identity

Every major stage gets its own visual identity while staying inside the same universe.

Examples:

- Cipher → encrypted intelligence console
- Firewall maze → security navigation system
- Dark room → near-black optical search interface
- Server color puzzle → holographic server rack
- Audio frequency → covert radio interception terminal
- Rotated protocol → corrupted display subsystem
- Memory map → high-detail intelligence image
- Quantum lock → unstable reactor / core interface
- Finale → cinematic system shutdown + celebration

## Images and assets

Whenever a stage benefits from a visual centerpiece, use a high-quality original illustration or generated asset.

Assets should look integrated into the interface:
- not stock-photo pasted into a rectangle
- not generic fantasy art
- not childish cartoon art

The preferred treatment is cinematic, dark, detailed, realistic/stylized-realistic, and consistent across the game.

## UI principle

No screen should feel like a form.

Even configuration screens should feel like an in-world operator console.

The player-facing game should prioritize:
**impact → clarity → interaction → feedback.**
